# Agent 任务记录

本目录保存并行 Agent 任务的文件化执行记录，用于避免多个 Worker 同时修改共享日志。

- 一项并行任务对应一个 Markdown 文件，文件名使用日期和简短名称，例如 `20260916-server-adapter.md`。
- 至少记录目标、修改范围、验收条件、base/branch/worktree、关键过程、验证结果和未决问题。
- 普通单 Agent 任务可以直接更新相关 `docs/` 文档，不强制在本目录新增文件。
- 长期有效的架构、研究、功能说明和项目状态仍应整理到 `docs/`；本目录不是长期文档的替代品。
- 不记录密钥、令牌、私人会话正文或真实用户数据。
